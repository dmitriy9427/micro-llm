# 3D-визуализация внимания

Как маленькая модель «смотрит» на слова: **этажи — слои**, **кубики — токены**, **светящиеся нити — внимание**. Чем ярче и теплее нить, тем сильнее токен смотрит на предыдущий. Работает на готовых JSON-файлах из `scripts/dump_attention.py`, модель в браузере не запускается.

```bash
python3 -m http.server 8000 --directory viz     # откройте http://localhost:8000
```

Управление: крутить мышью или пальцем; кнопки «Голова» (среднее по головам или одна) и «Слой»; клик по токену подсвечивает нити, идущие от него на всех этажах; наведение показывает, на какие токены он смотрит сильнее всего.

## Свои примеры

```bash
.venv/bin/python scripts/dump_attention.py --ckpt out-bpe/ckpt.pt --prompt "Ваш текст" --out viz/data/my.json
```

Добавьте файл в `viz/data/index.json` (`{"file": "my.json", "title": "…"}`), и он появится в списке.

## Как устроено

- `index.html` — страница и интерфейс; three.js подключается с CDN через import map (сборка не нужна).
- `app.js` — вся логика: башня из слоёв, дуги-нити по весам внимания (`LineSegments` с аддитивным смешиванием, поэтому нити светятся), выбор токена через `Raycaster`, камера подбирает расстояние под размер экрана.
- `data/*.json` — `{"tokens": [...], "layers": [слой][голова][i][j]}`. Строка `[i]` — как токен `i` распределяет внимание по токенам `j ≤ i`, сумма по строке равна 1.

Что видно: в BPE-модели токены-обломки русских слов показаны как `\xd0` (слова из двух байтов разрезаны посередине). В первых слоях много внимания «на соседа слева», выше нити длиннее.
